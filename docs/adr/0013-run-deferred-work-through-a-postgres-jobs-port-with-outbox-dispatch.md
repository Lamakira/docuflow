# Run deferred work through a Postgres jobs port with outbox dispatch

DocuFlow executes every deferred effect in the durable-worker runtime through a DocuFlow-owned jobs port backed by a PostgreSQL queue in the authoritative database, so enqueueing commits transactionally with domain writes and the HTTP runtime performs no background work. Domain events append once to an outbox event log — UUIDv7 id, versioned type, occurred-at, Workspace and principal provenance, aggregate reference, thin PII-minimized payload — and a dispatcher claims batches with `FOR UPDATE SKIP LOCKED` and fans out one job per registered consumer, giving at-least-once delivery, per-aggregate ordering only, per-consumer retry isolation, and a bounded replay window. Every job type declares attempts, backoff, timeout, and concurrency by class (domain-consequence, derived-processing, external-delivery); exhausted jobs land in a dead-letter table with full provenance, and replay is an audited operator command. Recurring work runs on a lease-elected scheduler tick in the worker runtime whose schedules live with their owning modules and expand into idempotent per-Workspace occurrence-keyed jobs with declared catch-up-or-skip semantics. Email keeps Resend behind a narrow port — Amazon SES is the named successor if hosting lands on AWS or an EU-residency customer arrives — while templates, delivery-event projections, and suppression stay DocuFlow-owned and emails carry only thin notification facts plus links. Notification fan-out materializes per-recipient rows with snapshot recipient resolution and read-time membership gating; notification rules live in the Notifications module, and Delivery Preferences apply per user, Workspace, Notification Category, and channel at delivery derivation, with in-app always on and security, billing, and membership classes mandatory. Adopting an external managed queue or workflow SaaS now, consumer cursors reading the outbox directly, producer-enqueued consumer jobs, provider-hosted email templates, compute-at-read inboxes, per-event-type preference matrices, and exactly-once delivery promises were all rejected.
