# Host on Render, Neon, and R2 with an independent AWS evidence account

DocuFlow launches its EU deployment on a PaaS-incremental bundle in Frankfurt: Render runs the two Docker runtimes from one image — a two-instance HTTP service and a durable-worker service with the in-app lease-elected scheduler — Neon hosts the authoritative PostgreSQL (Launch plan, Scale when compliance evidence or private networking is needed, scale-to-zero off, plain-SQL migrations and no Neon-only features so the database and compute vendors stay independently replaceable), and Cloudflare R2 with the `eu` jurisdiction stores workspace Files, screenshots, and Derived Artifacts behind the existing S3-shaped port with direct signed transfers. A standalone AWS account holds an S3 Frankfurt bucket with Object Lock in compliance mode for nightly encrypted logical database exports and closed audit-log segments — the immutable evidence copy ADR-0015 requires and the seed of the named AWS successor footprint — with its credentials confined to the backup job's environment group. Observability instruments once with OpenTelemetry through a collector into Better Stack (EU) for logs, metrics, uptime, heartbeats, on-call, and the public status page, plus Sentry (Germany) for web and desktop errors; telemetry carries IDs only. Secrets live in Render environment groups per ADR-0015; GitHub Actions deploys trunk-based through an in-repo Render Blueprint — auto-deploy staging, manual promotion to production, migrations as a gated pre-deploy step under expand/contract discipline with rollback by image redeploy, never down-migration. Cloudflare fronts the app with DNS, CDN, WAF, and edge rate limits as the US-latency mitigation on the EU data plane. Environments are production plus one synthetic-data staging of the same shape. Targets: 99.9% monthly internal HTTP SLO with no published SLA, a worker lag SLO of 95% of jobs started under 60 seconds, RPO ≤5 minutes via PITR, RTO ≤4 hours, daily independent logical exports, a quarterly timed restore drill with Erasure Journal replay recorded in-repo as compliance evidence, an annual restore-from-export independence drill, and an accepted-downtime posture for full EU-region outage with multi-region deferred to later regionalization. Paging is hard-failure-only with runbook links; every provider carries an 80%-of-budget spend alert against a €300–500/month launch ceiling reviewed monthly, with R2 stored-bytes growth watched and Tracking Policy retention as the structural storage-cost lever. Sized for launch at ≤25 Workspaces, ≤150 Members, and ≤100 Devices with ~10× headroom toward a month-12 envelope of ~200 Workspaces, ~1,500 Members, and ~1,000 Devices. AWS-first operation on ECS/Fargate, Fly.io, Render-managed Postgres, a single object-storage provider, Grafana-first observability, Terraform now, production-data staging, a published launch SLA, and v1 multi-region failover were all rejected.
