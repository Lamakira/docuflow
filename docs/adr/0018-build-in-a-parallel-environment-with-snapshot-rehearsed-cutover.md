# Build in a parallel environment with a snapshot-rehearsed cutover

Amends ADR-0017. The nine phases, their ordering, and their discipline — expand/contract deploys, temporary flags, verifiers, evidence trail — stand unchanged, but they execute in a fully isolated parallel environment rather than against the live production deployment. This repository is a separate copy with no link to the production repository or its Replit deployment, and it must never contain production credentials, production URLs, or any data-plane connection to production systems: the database is a new Neon account, and hosting, object storage, the evidence account, identity, and billing all use fresh accounts and secrets provisioned for this effort. Production data enters this environment only as restored snapshots — logical database exports loaded into scratch branches of the new Neon account and object-store copies into R2 — so every seed, backfill, classification, and import runs first, and repeatedly, against rehearsal data.

Three ADR-0017 mechanics change shape as a consequence. The Phase 2 hosting lift becomes standing up the parallel environment with no production traffic on it. The live-drain mechanics — the Clerk dual-auth session drain window and the GCS-to-R2 dual-write window — presumed migrating a live system under its users and are replaced by snapshot rehearsal of the same transformations. Production cutover becomes one late, rehearsed event inside an announced freeze window: final export and import from the old stack, a full run of the already-rehearsed migration pipeline, verifiers green, then the traffic switch and forced desktop-fleet update to the new environment; the old production stack keeps running untouched as instant rollback until confidence is established, and is retired only afterwards. Evolving the live production deployment through the phases, as ADR-0017 originally described, was rejected once full isolation became the mandate — the trade accepts one larger, rehearsed cutover day in exchange for never exposing production to in-flight migration work.
